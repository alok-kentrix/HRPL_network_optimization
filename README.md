# HRPL Network Optimization

Nightly route optimization across three distribution centres — Mumbai (KLM), Bengaluru (BLR)
and Ahmedabad (AHM) — covering 31 August to 5 September 2026.

The dashboard puts every night's optimized plan on the real road network beside the dispatch
HRPL actually ran, with both layers priced on the same agreed tariff so the comparison is
like for like. Filter by distribution centre and by night; the map, the KPIs, the summary
and the analysis all follow the selection.
